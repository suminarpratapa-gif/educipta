Penyunting Visual Modul Ajar

Modul tampil seperti di web. Sorot teks yang ingin diubah, lalu pilih aksi pada toolbar yang muncul di dekat sorotan. Semua proses berjalan di peramban Anda; file tidak dikirim ke mana pun.

Klik untuk memilih file .html, atau seret file ke sini File asli tidak diubah. Suntingan disimpan ke file baru: nama asli + _sunting_ + tanggal.

Cara pakai

  1. Buka file modul. Setelah modul tampil, klik Mau sunting? (atau Tidak sunting bila hanya ingin melihat).
  2. Sorot (blok) teks pada modul dengan tetikus. Toolbar muncul di dekat sorotan.
  3. Pilih aksi: B tebal, I miring, U garis bawah, x2 subskrip, x2 superskrip, Ganti teks, Hapus teks, Hapus poin/paragraf, atau Hapus format. Klik tombol format lagi untuk melepasnya. Menu Font, Ukuran, dan Paragraf berisi pilihan huruf, ukuran huruf, posisi teks (rata kiri, tengah, rata kanan, rata kiri-kanan), inden, tab, baris baru, serta bullet dan nomor.
  4. Klik Simpan (Ctrl+S) kapan saja. Salah langkah? Batalkan langkah (Ctrl+Z).
  5. Pratinjau Hasil membuka hasil di tab baru, lengkap dengan animasi dan kuisnya.
Klik Mau sunting? untuk mulai. Sebelum itu modul hanya bisa dilihat.

Riwayat perubahan

    Belum ada perubahan.

    Enter = terapkan, Esc = batal. Format teks awal ikut terbawa.
